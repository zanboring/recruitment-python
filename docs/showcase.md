# AI 招聘数据可视化系统 · 项目展示

> 一句话：以真实招聘数据为数据源，做「**可评估、可观测、可控成本**」的 AI 招聘助手，
> 而不只是「把 LLM 接进聊天框」。定位：AI 应用开发 / LLM 应用工程师岗位的后端作品。

---

## 为什么值得看（核心差异化）

大多数 AI 项目只做到「能跑通 RAG / 工具调用」，却回答不了三个问题：

| 问题 | 本项目的答案 |
|---|---|
| 检索到底有没有效果？ | **自建黄金集量化**：关键词检索对口语化改写（问「工资」、条目写「薪资」）命中率 **0%**，语义向量提升到 **93.8%**，RRF 混合整体 Hit@5 **96.4%**（`docs/reports/rag-evaluation.md` 可复现，向量化用本地 `qwen3-embedding:0.6b`） |
| 每次调用花多少钱、降级有没有生效？ | **每次 LLM / 向量化调用都落库**：token、耗时、降级层级、失败原因，按场景/模型/服务商聚合，成本可算、降级可查 |
| 本地模型怎么用才不浪费？ | **按能力分工而非互为备份**：基准脚本实测后，机械的「工具识别」交给小模型、需要事实准确性的「对话生成」交给大模型 |

## AI 能力全景

- **三级降级链**：云端（DeepSeek → 智谱多供应商容灾）→ 本地 Ollama（`qwen3.5:4b`）→ 规则引擎兜底，任一后端故障服务不中断
- **RAG**：embedding-3 向量检索 + RRF 混合检索 + 关键词降级，检索结果带引用溯源（`event: sources`）
- **Function Calling + ReAct Agent**：单步查库之外，支持「先查总量 → 再看分布 → 再要推荐」的多步推理，每步 Thought/Action/Observation 可透出、可核查
- **成本与熔断**：云端连续失败 3 次进 OPEN 熔断；输出长度分级设限；Token 用量落库统计
- **可观测**：每次回答的 provider / 模型 / 降级层级 / 耗时通过 `event: meta` 透出

## 快速开始（5 步）

```bash
pip install -r requirements.txt
cp .env.example .env           # 仅需填 DEEPSEEK_API_KEY（留空自动降级本地/规则引擎）
python scripts/init_db.py      # 建表 + 播种 admin / admin123
python run_entry.py            # 默认 http://127.0.0.1:8080，接口文档在 /docs
python -m pytest -o addopts= -q   # 946 项全绿，无需密钥即可跑通
```

> Windows 上也可以直接双击 `start.bat`（源码模式：自动建 venv、装依赖、建库、起服务并开浏览器）；
> 绿色版用 `start-generic.bat`（需先 `cp config.template.env config.env`）。
> ⚠️ 没有 `python -m app.main` 这个入口 —— `app/main.py` 只导出 `create_app()`。

## 面试三分钟讲法（配合代码）

> **开场**：「这不是把 LLM 当聊天框接进来的项目。我做的是一个可评估、可观测、可控成本的 AI 应用：
> 招聘数据来自真实爬取，AI 能调工具查真库、能做 RAG，而且我知道它的检索效果是多少、每次调用花多少钱、
> 降级有没有真的生效。」
>
> **亮点 1（用数据说话）**：建黄金集把查询分字面型/语义型，实测关键词检索语义型命中 0%，语义向量拉到 93.8%。
> **亮点 2（成本可观测）**：工具识别有廉价前置过滤省 ~2.9s/次；每次调用落库可回答「贵在哪、降级了吗」。
> **亮点 3（本地模型怎么用）**：先跑基准再决定路由，不靠直觉。机械的「工具识别」交给本地小模型，
> 省时省钱；需要事实准确性的「对话生成」交云端。8 GB 显存上试过 `qwen2.5:14b`，实测只能 offload
> （**12.2 tok/s**，比小模型更慢），于是统一收敛到 `qwen3.5:4b` —— 为"看起来更强的模型"牺牲可用性不值。
>
> **主动暴露取舍（显得可信）**：四类运行态（限流 / 熔断 / 爬虫配额 / AI 会话）**默认走进程内存** ——
> 单机够用、零依赖；多副本需显式切 Redis（该能力已实现，并按「双进程对照」验证过跨副本生效）。
> 向量与知识库缓存复用同一个 `app.cache` 层：未接 Redis 时重启需重算；
> 初始管理员口令按「环境变量 > 生产随机生成并落盘 > 开发默认」取值，日志不输出明文。
