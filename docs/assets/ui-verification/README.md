# 浏览器端实测截图（2026-09-10）

用 playwright-core + 系统 Chrome（headless）对运行中的前后端做的真实渲染验证，
是「P0-1 前端实测」的完成证据。验证脚本共 17 项断言，全部通过。

## ai_chat_with_citation_and_meta.png

验证点：
- **正文干净**：AI 回复不含 SSE 的 `data:` 前缀与 `event:` 残留
  （修复前前端直接拼接原始字节，协议格式会显示给用户）；
- **引用来源区**：「依据 1 条知识库资料」折叠区正常渲染，展开可见来源条目
  —— `event: sources` 从后端检索到 UI 展示全链路打通；
- **模型元信息标签**：气泡底部「规则引擎（已降级）· 规则引擎」
  —— `event: meta` 生效，用户能明确知道本轮是降级回答而非模型输出。

## crawl_dialog_dynamic_options.png

验证点：
- **平台下拉来自后端**：BOSS直聘可选中；前程无忧 / 猎聘 / 智联招聘
  标注「暂未支持采集」（原先硬编码 4 个平台，用户能选到必然失败的项）；
- **城市共 20 个**（原先硬编码 11 个，一半可用城市看不到）；
- 背景任务列表：平台显示中文名「智联招聘」，说明列展示失败原因原文。
